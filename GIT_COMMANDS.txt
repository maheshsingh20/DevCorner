# Git Commands to Push Your Project to GitHub

## Step 1: Initialize Git Repository
git init

## Step 2: Add All Files
git add .

## Step 3: Commit Changes
git commit -m "Initial commit: Hospital Management System with DevOps automation"

## Step 4: Set Main Branch
git branch -M main

## Step 5: Add Remote Repository
git remote add origin https://github.com/maheshsingh20/DevCorner.git

## Step 6: Push to GitHub
git push -u origin main

## ============================================
## Additional Useful Git Commands
## ============================================

## Check Status
git status

## View Commit History
git log --oneline

## Create a New Branch
git checkout -b feature/new-feature

## Switch Branches
git checkout main

## Pull Latest Changes
git pull origin main

## Add Specific Files
git add README.md
git add maint.tf

## Commit with Detailed Message
git commit -m "Add feature" -m "Detailed description of changes"

## Push to Specific Branch
git push origin feature/new-feature

## View Remote URLs
git remote -v

## Remove File from Git (keep local)
git rm --cached filename

## Undo Last Commit (keep changes)
git reset --soft HEAD~1

## View Changes
git diff

## ============================================
## IMPORTANT: Before Pushing
## ============================================

1. Make sure .gitignore is working:
   git status
   
   You should NOT see:
   - Dev.pem
   - terraform.tfvars
   - *.tfstate files
   - .terraform/ directory

2. If sensitive files appear, remove them:
   git rm --cached Dev.pem
   git rm --cached terraform.tfvars
   git commit -m "Remove sensitive files"

3. Verify .gitignore:
   cat .gitignore

## ============================================
## Creating GitHub Repository
## ============================================

If you haven't created the repository yet:

1. Go to https://github.com/maheshsingh20
2. Click "New Repository"
3. Name: DevCorner
4. Description: Hospital Management System with DevOps Automation
5. Keep it Public or Private
6. DON'T initialize with README (we already have one)
7. Click "Create Repository"
8. Use the commands above to push

## ============================================
## Updating README with Screenshots
## ============================================

After pushing, you can add screenshots:

1. Create a 'screenshots' folder in your repo
2. Upload images via GitHub web interface
3. Update README.md image links
4. Commit and push changes

## ============================================
## Tags and Releases
## ============================================

## Create a Tag
git tag -a v1.0.0 -m "First release"

## Push Tags
git push origin --tags

## Create Release on GitHub
1. Go to your repository
2. Click "Releases"
3. Click "Create a new release"
4. Select tag v1.0.0
5. Add release notes
6. Publish release
